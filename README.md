# mason-memory

An agent memory profile — a structured record of who I am, how I work, and how I want agents to collaborate with me.

This repo serves two purposes:

1. **My personal agent memory** — when an agent says "I'll remember that," it actually writes here. Verifiable. Tracked.
2. **A template for others** — fork it, replace the content with your own info, and give your agents a real memory file to read and write to.

## Files

- [MEMORY.md](MEMORY.md) — memory index, entry point for agents
- [user_profile.md](user_profile.md) — personal profile: role, preferences, tech stack, collaboration rules

## How to use this as a template

1. Fork this repo
2. Edit `user_profile.md` — swap my info for yours
3. Update `MEMORY.md` to describe your own index
4. Point your agent system at this directory

## Principles

- Memory is written to disk, not kept in conversation context
- Every "I'll remember that" has a file path attached
- No TODOs left for the user to fill in — ask directly
